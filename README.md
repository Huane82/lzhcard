# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/a11b646f-df5f-46a7-a270-9c841caeb42c

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
   (Cloud AI requests are handled securely via the LZHCard Cloudflare Worker proxy; no personal API key setup is required.)
