AI 雲端解析資料隱私授權

僅於您主動使用雲端 AI 翻譯、拍照 OCR 或螢幕翻譯時傳輸必要資料

當您啟用雲端 AI 功能時，LZHCard 會依所選服務將以下資料進行加密傳輸：

  • 傳送內容：您主動拍攝或選取的照片影像、欲查詢或翻譯的字詞與例句文字片段。
  • 第三方 AI 處理方：Google Gemini API、Groq API 及 LZHCard Cloudflare Worker 中繼站，僅用於即時回傳釋義、OCR 辨識與翻譯結果，不會用於廣告追蹤或身分販售。
  • 離線選擇：若您不同意雲端傳輸，核心單字卡記憶（FSRS）、本機字庫複習及 Apple 裝置端離線翻譯／Tesseract 本地辨識仍可正常運作。

LZHCard 隱私權政策 (Privacy Policy)

1. 資料收集範圍與本機優先原則

LZHCard 以裝置端學習體驗為核心。您的單字庫、FSRS 記憶進度與個人偏好設定預設儲存在裝置的 LocalStorage 與 IndexedDB 中；僅當您選擇使用 Google 或 Apple 帳號登入時，才會透過 Firebase Authentication 與 Cloud Firestore 同步您的學習紀錄與公開名片資料。

2. 相機、照片與螢幕翻譯（AI 資料傳輸）

您可優先選擇裝置端離線辨識（Apple Vision / Translation 或本地 Tesseract）。僅於您明確同意授權並觸發雲端 AI 功能（如單字解析、拍照 OCR 翻譯、字幕語境精修）時，系統才會透過 HTTPS 加密將必要文字或影像片段傳送至 Google Gemini API、Groq API 或 LZHCard Cloudflare Worker 中繼服務即時運算，運算完成後不會留存您的私人影像。

3. 不進行跨 App 廣告追蹤與資料販售

本應用程式不包含第三方廣告 SDK，不追蹤您於其他公司應用程式或網站的活動（NSPrivacyTracking = false），亦絕不販售或出租任何個人資料。

4. 帳號刪除與資料控制權

您可隨時於「設定 → 帳號與備份」匯出 JSON 備份，或使用「永久註銷帳號」功能立即清除雲端 Firestore 分片資料、公開名片與認證帳號，以及本機所有快取。
